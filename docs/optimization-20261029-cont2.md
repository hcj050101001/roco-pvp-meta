## 无障碍覆盖

- axe WCAG 2/2.1 A/AA 的自动检查从首页、历史页和一张详情页扩到时间线、阵容对比、体系共现；当季或历史超过每页 24 套时，测试会自动加入全部实际生成的静态分页页。本轮为 15 套当季和 4 套历史，额外静态页数为 0。
- 新增原生下拉框的键盘选择与相同阵容提示、图中标签的 Tab/Enter 操作、静态分页在无脚本状态下的上一页/下一页，以及启用脚本后从第 2 页进入详情并返回的键盘检查。静态分页检查只在真实页面存在时生成。浏览器测试本轮未运行，因此这些交互仍待 Muse 验证。
- 共现 SVG 的 26 个标签由不可聚焦文字改为可聚焦链接，链接指向下方按体系列出的真实关联阵容；焦点有可见描边，目标有背景提示。列表只从已有已核验阵容的体系标签产生，不补写阵容事实。`systems/index.html` 从改动前的 25,524 B 增至 33,713 B，增加的 8,189 B 包含新链接列表和结构化数据；实际传输量未测。

## 自审计改进

- **性能：** 列表页的 `LineupCard` 与 `Collection` 原本都会调用图片失败监听初始化，服务端卡片被重复扫描、重复绑定。现在由 `Collection` 对初始卡片调用一次，动态卡片继续在插入时初始化。根路径构建的 JS 产物由 5 个文件、11,335 B 降为 3 个文件、11,189 B（原始字节合计减少 146 B）；这只证明脚本与请求数减少，不代表加载时间或 Core Web Vitals 改善。既有图片失败浏览器用例待 Muse 运行。
- **SEO 与结构化数据：** 历史、时间线、对比和共现四个既有浏览入口的 `BreadcrumbList` 从各 0 份变为各 1 份；未来生成的静态分页也有与实际页码对应的面包屑。构建校验会解析 JSON-LD，核对首项是站点根、末项是当前 canonical，且位置连续、名称非空。根路径和 `/roco-pvp-meta` 子路径构建均通过。未声称搜索排名变化。
- **发现深度：** 共现图新增 26 个可直接访问的体系标签目标，标签下列出对应已核验阵容入口；图上链接与文字列表共享同一目标，键盘或触屏均可使用。产物检查确认有 26 个图中标签链接和一个体系列表。
