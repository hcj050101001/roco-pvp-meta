# 页面视觉与验收

## 视觉方向

使用固定的暖白纸面、深色正文和轻量蓝色强调。首页、往期页、详情页与 404 页共享同一套设计；不随赛季改变色彩。

- 全局样式和设计变量位于 `src/styles/player.css`；图标使用 `src/components/Icon.astro` 的内联 SVG，无额外图标依赖或外部字体请求。
- 首页和历史页的大标题使用系统中文衬线字体，正文使用系统无衬线字体。不同操作系统的字形可以略有不同。
- 赛季封面为装饰性几何图形，赛季名称和数量来自现有数据；不充当配置图片。
- 首页依次展示赛季介绍、数量概览、搜索筛选和阵容卡片。推荐排序的解释放在可展开的说明中。
- 卡片保持完整原图、统一 4:3 容器和 `object-fit: contain`。同排标题与底部操作区对齐；配置详情与视频分别使用独立链接。
- 详情页突出完整配置图，桌面提供固定侧栏，手机端使用单列。历史赛季标记、真实日期、署名与来源保留。
- 桌面三列卡片，中等屏幕两列，580px 及以下单列。700px 及以下调整封面、搜索区、导航与页脚布局。
- 控件有键盘焦点提示。视频筛选保留原生复选框语义；清除筛选恢复搜索焦点并保留无关 URL 参数和片段。减少动态效果偏好下关闭动画与平滑滚动。
